大车防撞录包程序：报警前 2 秒预录功能虚拟测试

一、复制规则
============

【整块复制】表示：把该标题下面的整个命令块一次性复制到对应终端执行。
【不要复制】表示：这是预期结果或说明，只用于核对。

本次所有命令块都已标明复制方式。不要把“通过标准”和“预期结果”复制进终端。


二、本次测试目标
================

1. 新版本能完成编译，并执行 alarm_state、pre_record_buffer 两个单元测试。
2. 左右节点参数均为 pre_record_seconds=2.0、pre_record_max_mb=128。
3. 报警前持续到达的本组两路点云和 PLC 能写入事件 bag。
4. bag 的最早消息时间早于报警触发时间，并接近提前 2 秒。
5. 触发消息不会因“缓存补写+实时写入”而重复。本流程每包的报警 Topic 应为两条：一条触发、一条解除。
6. 第一包关闭以后缓存继续工作，第二次报警仍能写入报警前数据。
7. 左右两个实例都能预录各自的两路点云。

本流程使用 ROS_DOMAIN_ID=98，与现场 ROS 域隔离。虚拟 PointCloud2 是空消息，只验证预录时序、状态机和 DB3 写入；不验证真实点云吞吐、真实点云单帧大小、现场内存占用或长期稳定性。

六、终端 3：执行三次预录事件
==============================

终端 1 和终端 2 均正常运行后再执行。三次事件之间特意等待 4 秒，使上一次报警消息离开 2 秒缓存；这样每包报警 Topic 应准确为两条。

【整块复制：从 cd 开始，到最后一次 bag_count 结束】

cd /home/dnt/ws_ros2_rtg
source /opt/ros/humble/setup.bash
source /home/dnt/ws_ros2_rtg/install/setup.bash
export ROS_DOMAIN_ID=98

alarm()
{
  ros2 topic pub /algl/GantryColDetMsg rtg_algorithm_interfaces/msg/SafetyDetectMsg "{area_code: $1, has_object: false, object_distance: $2}" --once
}

bag_count()
{
  find /home/dnt/ws_ros2_rtg/virtual_test_output/gantry_pre_record -mindepth 2 -maxdepth 2 -type d -newer /tmp/gantry_pre_record_test_start | wc -l
}

# 先建立四个区域的明确正常状态，再等待超过 2 秒，让这些初始化消息退出缓存。
alarm 1 20.0
alarm 2 20.0
alarm 3 20.0
alarm 4 20.0
sleep 4
echo '初始化后 bag 数，预期 0：'
bag_count

# 用例 1：第一次左侧事件。触发前点云和 PLC 已持续发布 4 秒。
alarm 1 10.0
sleep 1
alarm 1 20.0
sleep 5
echo '用例 1 后累计 bag 数，预期 1：'
bag_count

# 让上一事件的报警消息退出缓存，但点云和 PLC 缓存继续滚动更新。
sleep 4

# 用例 2：第二次左侧事件，验证关包后下一事件仍有预录数据。
alarm 3 4.0
sleep 1
alarm 3 20.0
sleep 5
echo '用例 2 后累计 bag 数，预期 2：'
bag_count

sleep 4

# 用例 3：右侧事件，验证右实例也能预录自己的 L20、L19 和 PLC。
alarm 2 10.0
sleep 1
alarm 2 20.0
sleep 5
echo '全部用例后累计 bag 数，预期 3：'
bag_count

【不要复制：终端 3 通过标准】

- 初始化后为 0。
- 用例 1 后为 1。
- 用例 2 后为 2。
- 全部完成后为 3。
- 终端 2 每个事件只打印一次“开始录包”和一次“结束录包”。

【不要复制：复制 A 的通过标准】

- 左右参数均为 pre_record_seconds=2.0、pre_record_max_mb=128。
- 总数为 3，其中 left=2、right=1。
- 三个 event.txt 都是 status=alarm_cleared、pre_record_seconds=2。

【整块复制 B：用 SQLite 时间戳精确判断是否写入报警前数据】

python3 - <<'PY'
from pathlib import Path
import sqlite3

root = Path('/home/dnt/ws_ros2_rtg/virtual_test_output/gantry_pre_record')
marker = Path('/tmp/gantry_pre_record_test_start').stat().st_mtime_ns
bags = sorted(
    path for path in root.glob('*/*')
    if path.is_dir() and path.stat().st_mtime_ns > marker
)

passed = True
print(f'本轮事件数={len(bags)}，预期=3')
if len(bags) != 3:
    passed = False

for bag in bags:
    event = {}
    for line in (bag / 'event.txt').read_text().splitlines():
        if '=' in line:
            key, value = line.split('=', 1)
            event[key] = value

    topic_counts = {}
    first_timestamp = None
    for database in sorted(bag.glob('*.db3')):
        connection = sqlite3.connect(database)
        for name, count in connection.execute(
            'SELECT topics.name, COUNT(messages.id) '
            'FROM topics LEFT JOIN messages ON topics.id=messages.topic_id '
            'GROUP BY topics.id'
        ):
            topic_counts[name] = topic_counts.get(name, 0) + count
        current_first = connection.execute('SELECT MIN(timestamp) FROM messages').fetchone()[0]
        connection.close()
        if current_first is not None:
            first_timestamp = current_first if first_timestamp is None else min(first_timestamp, current_first)

    trigger = int(event['start_receive_time_ns'])
    requested = int(event['requested_record_from_ns'])
    lead_ms = (trigger - first_timestamp) / 1_000_000
    requested_ms = (trigger - requested) / 1_000_000
    alarm_count = topic_counts.get('/algl/GantryColDetMsg', 0)
    status = event.get('status')
    bag_ok = (
        status == 'alarm_cleared'
        and 1500 <= lead_ms <= 2300
        and 1999 <= requested_ms <= 2001
        and alarm_count == 2
        and len(topic_counts) == 4
        and all(count > 0 for count in topic_counts.values())
    )
    passed = passed and bag_ok
    print(f'{bag.name}: status={status}, 实际预录={lead_ms:.1f}ms, 请求预录={requested_ms:.1f}ms, 报警消息={alarm_count}, Topic数={len(topic_counts)}, 结果={"通过" if bag_ok else "失败"}')
    for name, count in sorted(topic_counts.items()):
        print(f'  {name}: {count}')

print('预录功能总结果：' + ('通过' if passed else '失败'))
raise SystemExit(0 if passed else 1)
PY

【不要复制：复制 B 的通过标准】

- 三个事件的“实际预录”均在 1500～2300 ms。
- “请求预录”均约为 2000 ms。
- 报警消息均为 2，Topic 数均为 4，所有 Topic 计数大于 0。
- 最后一行必须是“预录功能总结果：通过”，并且命令退出码为 0。

九、验收边界
============

通过本流程后，可以确认：编译、两个纯状态测试、2 秒虚拟预录、连续两次事件缓存保留、左右独立、触发消息不重复、event.txt 与 DB3 可读。
